# Calculator

## Objective
A browser-based calculator developed as part of the Oasis Infobyte Web Development Level 2 internship.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Features
- Basic arithmetic operations
- Numbers 0–9
- Decimal input
- Clear button
- Backspace button
- Equals button
- Operator chaining
- Division-by-zero error handling
- CSS Grid button layout
- Responsive user interface

## How to Run

1. Download or clone the repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a web browser.

## Project Structure

- `index.html` - Calculator structure
- `style.css` - Calculator styling
- `script.js` - Calculator functionality
