# To-Do Web App

## 📌 Project Overview

This project is a simple and responsive To-Do Web Application developed as part of the Oasis Infobyte Web Development Internship.

The application allows users to add, edit, complete, and delete tasks while keeping track of pending and completed tasks.

## 🎯 Objective

The objective of this project is to create a functional task management application using HTML5, CSS3, and Vanilla JavaScript.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- View all tasks
- View pending tasks
- View completed tasks
- Display task counts
- Empty state when there are no tasks
- Save tasks using browser Local Storage
- Responsive design for desktop, tablet, and mobile devices
- Press Enter to quickly add a task

## 📂 Website Sections

1. Header
2. Add Task Section
3. Task Statistics
4. Task Filters
5. Task List
6. Empty State
7. Footer

## 💾 Local Storage

The application uses browser Local Storage to save tasks.

This means tasks remain available even after refreshing or reopening the webpage in the same browser.

## 🚀 How to Run the Project

1. Open the `WebDev-L2-ToDoApp` folder.
2. Open the project in VS Code.
3. Open `index.html` using Live Server.
4. Add tasks and test the application.
