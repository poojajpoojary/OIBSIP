# Tribute Page – Dr. A. P. J. Abdul Kalam

## 📌 Project Overview

This project is a responsive tribute page dedicated to **Dr. A. P. J. Abdul Kalam**, one of India's most respected scientists and former President of India.

The webpage presents his life, achievements, contributions to science and education, and his inspiring legacy in a simple and attractive design.

## 🎯 Objective

The objective of this project is to create a responsive and visually appealing tribute webpage using HTML5 and CSS3.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Responsive Web Design

## ✨ Features

- Attractive hero section
- Dr. A. P. J. Abdul Kalam's portrait
- Biography section
- Life journey timeline
- Major achievements
- Inspirational quote section
- Legacy section
- Responsive design for mobile and desktop screens
- Multiple background colors
- Different font styles and typography

## 📂 Website Sections

1. Hero Section
2. Portrait Section
3. Biography – His Life
4. Timeline – His Journey
5. Inspirational Quote
6. His Legacy
7. Footer

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the `WebDev-L2-TributePage` folder.
3. Open `index.html` in a web browser.

For development, the project can also be opened using the **Live Server** extension in VS Code.
